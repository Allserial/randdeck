# 掷数台使用说明

## 启动

- 单文件版：双击 `掷数台.exe`。
- 便携完整包：先完整解压 ZIP，再双击其中的 `掷数台.exe`。
- 离线安装版：运行 `掷数台-离线安装版-setup.exe` 并按提示安装。

## 基本抽取

1. 选择范围池、自定义池或骰子表达式。
2. 设置数据源、抽取数量、排除规则和“抽后移除”。
3. 点击“生成结果”，或在非输入状态下按 `Space` / `Enter`。
4. 使用 `Shift+Space` 启动当前设置的倒计时生成。

## 结果操作

- 点击数字卡片进行选择。
- “重掷所选”只重新生成所选卡片。
- “固定所选”会在下一次普通生成时保留固定卡片。
- “加入排除”会把所选数字加入当前排除规则。
- “撤销抽取”会回滚最近一笔抽取及对应统计。

## 数据与备份

- 历史、设置和预设默认保存在本机。
- 关闭再启动后结果舞台为空，但历史记录仍保留。
- 清空历史会同步清空结果舞台，但不会清空统计账本。
- 迁移电脑或卸载前，请在设置中导出完整 JSON 备份。

## 文件校验

PowerShell 中执行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\掷数台.exe'
```

将结果与 Release 页面或 `SHA256SUMS.txt` 中的值比较。不同则不要运行。

## 常见提示

- SmartScreen 显示“未知发布者”：当前版本未购买代码签名证书。请确认下载来源和 SHA256 后再决定是否运行。
- 单文件版无法启动：安装或更新 Microsoft Edge WebView2 Runtime，或者使用离线安装版。
- 资源管理器仍显示旧图标：按 `F5` 刷新，必要时重新打开该文件夹。
