# RandDeck / 掷数台使用说明

## 安装与启动

- **单文件便携版（`RandDeck.exe`）**：Windows 11 默认已自带 WebView2 Runtime，下载后直接双击即可运行。
- **便携压缩包（`RandDeck-v0.7.0-portable.zip`）**：请先完整解压到文件夹，再双击里面的 `RandDeck.exe`。
- **离线安装版（`RandDeck-v0.7.0-offline-setup.exe`）**：如果目标电脑较老、没有 WebView2 环境，或者你想创建开始菜单/桌面快捷方式、从旧版本直接覆盖升级，请运行此安装包。

当前版本未购买商业代码签名证书，首次启动时 Windows SmartScreen 可能会弹出“未知发布者”提示。建议运行前先核对文件 SHA256 是否与 GitHub Release 页面一致。

## 语言与外观

打开顶部导航的 **设置**，可以随时切换 **简体中文 / English**，或切换 **标准墨蓝 / 暖灰浅色 / 高对比** 主题。
动态效果默认为“标准”；如果你在活动现场需要悬念感，可以切到 **仪式** 模式，展开设置 `3s / 5s / 10s` 倒计时、逐个揭示开关和流金粒子效果开关。

## 三种抽取方式

- **范围池**：填入最小值和最大值，适合抽学号、工号、座位号或编号。支持排除指定数字、区间（如 `1..10`）或奇偶数，也可开启“抽后移除”避免重复抽中。
- **自定义池**：自己录入名单或导入 CSV 表格，支持为不同条目设置权重和标签分组。
- **骰子表达式**：输入如 `2d6+3`、`2d20kh1`（优势检定保留最高）、`4d6kh3`（属性点生成）等算式，结果卡片会同时展示总点数、2D 多面骰图标与算式明细。

在非输入框焦点下，按 `Space` 或 `Enter` 立即抽取；按 `Shift+Space` 启动倒计时抽取。

## 卡片操作与批次备注

- **局部操作**：点击结果卡片可选中它，随后可“重掷所选”“固定所选”（下一轮保留该卡片）或“加入排除”；点错了也可一键“撤销本次抽取”。
- **添加备注**：点击舞台左下角的 **+ 备注**，或右键点击底部“最近批次”里的历史卡片，即可为该批结果写上备注（如“一等奖”“先攻检定”），方便之后在“数据洞察”中按关键词查找。

## 本机存档与备份

所有历史记录、统计数据和预设都只保存在本机（桌面版位于 `%APPDATA%\com.zhishutai.desktop\state-v5.json`），软件完全不联网。
清空历史记录时会一并清空当前舞台，但不会抹掉累计的分布统计；如需清空统计可在“数据洞察”中单独重置。换电脑或重装系统前，可在“设置”中导出完整 JSON 备份。
